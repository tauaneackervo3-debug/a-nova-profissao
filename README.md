# Landing page — Lucas Córdova

Site estático com identidade preto/azul, imagens locais, biografia de Lucas Córdova e carrossel responsivo de provas sociais.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Selecione **Other** como framework.
3. Use a raiz do repositório como Root Directory.
4. Não configure comando de build nem de instalação; o site já está pronto.
5. Publique com **Deploy**.

`index.html` é a página principal. `assets/` contém imagens e fontes. `vercel.json` configura o cache dos arquivos estáticos.

Os oito botões de compra apontam para o checkout Kiwify configurado na página. No celular, o carrossel mostra uma imagem por vez, com avanço automático a cada quatro segundos.
